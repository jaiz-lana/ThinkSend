ThinkSend

Versi 0.3.0 • PWA Offline-First

Aplikasi web transfer file cepat lintas jalur secara langsung antar perangkat tanpa server penyimpanan file, menggunakan antarmuka terang bergaya Telegram dengan motif Batik Parang.

  • QR Optik: Transfer 100% offline via layar & kamera dengan verifikasi SHA-256.
  • WLAN: Radar Wi-Fi otomatis, Kode Ruang / Scan QR, serta mode Offline Murni (QR Offer/Answer) dengan enkripsi E2EE (ECDH P-256 + AES-256-GCM + PIN/SAS).
  • Provider: Transfer P2P jarak jauh terenkripsi End-to-End melalui kode sesi ringkas + verifikasi SHA-256.
